Unity + WPF Machine Simulation Academy v2.0

index.html → lessons/lesson-001.html ~ lesson-150.html
assets/ : 공통 CSS 및 진도/메모 JS (기존 저장 키 유지)
examples/ : 67개 개별 실습 파일. 해당 강의의 지시에 따라 선택 복사합니다.

실행: 압축을 모두 풀고 index.html을 엽니다. 진도 저장은 Python 설치 후 start.bat으로 로컬 서버를 실행하는 것을 권장합니다. 기존과 같은 브라우저 및 localhost 포트에서 사용하세요.

150개 강의에 이론, 실습 단계, 예제 또는 설정, 검증, 오류 해결, 복습을 포함합니다. 실제 공식 스크린샷은 일부 강의에서 원본 URL을 참조하므로 인터넷이 필요합니다. 자체 도식은 실제 스크린샷이 아닙니다. Unity/FreeCAD/WPF 실행 및 모든 코드의 컴파일 테스트는 수행하지 않았습니다. 복합 통합, 산업 프로토콜, 배포는 사용자 Windows 환경에서 구현 및 검증이 필요합니다. 실제 기계 안전 제어/구조해석을 대신하지 않습니다. Unity Industry 전용 기능은 사용하지 않지만 상업적 라이선스 자격은 별도로 확인해야 합니다.
