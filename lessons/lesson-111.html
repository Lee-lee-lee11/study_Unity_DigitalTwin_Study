111강. 카메라 제어

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

카메라를 Pivot 주변에서 회전하고 거리 제한을 둔다.

핵심 개념

Orbit, Pan, Zoom으로 기계 관찰을 지원한다.

원리와 실무 적용

Orbit은 중심점 기준 yaw/pitch 및 거리로 위치를 계산한다. pitch와 거리 제한 필요.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. Main Camera에 OrbitCamera.cs 연결

02. target=MachineRoot

03. 우클릭 yaw/pitch, 휠 거리

04. 1~20 m 제한

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

OrbitCamera.cs

파일 다운로드

using UnityEngine;

public class OrbitCamera : MonoBehaviour
{
    public Transform target;public float distance=5,yaw=45,pitch=30;
    void LateUpdate(){if(!target)return;if(Input.GetMouseButton(1)){yaw+=Input.GetAxis("Mouse X")*5;pitch-=Input.GetAxis("Mouse Y")*5;}
     pitch=Mathf.Clamp(pitch,-80,80);distance=Mathf.Clamp(distance-Input.mouseScrollDelta.y,1,20);
     Quaternion q=Quaternion.Euler(pitch,yaw,0);transform.SetPositionAndRotation(target.position-q*Vector3.forward*distance,q);}
}
