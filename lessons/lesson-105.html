105강. HwndHost

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

HwndHost 파생 클래스로 빈 Win32 자식 창을 생성하고 해제한다.

핵심 개념

WPF 안에서 네이티브 자식 창을 호스팅한다.

원리와 실무 적용

HwndHost는 BuildWindowCore에서 자식 창을 반환하고 DestroyWindowCore에서 정리한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

NativeViewport.cs

파일 다운로드

using System;
using System.ComponentModel;
using System.Runtime.InteropServices;
using System.Windows.Interop;
public sealed class NativeViewport : HwndHost {
 public IntPtr HostHandle {get;private set;}
 [DllImport("user32.dll",CharSet=CharSet.Unicode,SetLastError=true)]
 static extern IntPtr CreateWindowEx(int exStyle,string cls,string name,int style,int x,int y,int w,int h,IntPtr parent,IntPtr menu,IntPtr instance,IntPtr param);
 [DllImport("user32.dll",SetLastError=true)] static extern bool DestroyWindow(IntPtr hwnd);
 protected override HandleRef BuildWindowCore(HandleRef hwndParent){
  HostHandle=CreateWindowEx(0,"STATIC","Unity host",0x50000000,0,0,1,1,hwndParent.Handle,IntPtr.Zero,IntPtr.Zero,IntPtr.Zero);
  if(HostHandle==IntPtr.Zero)throw new Win32Exception(Marshal.GetLastWin32Error());return new HandleRef(this,HostHandle);
 }
 protected override void DestroyWindowCore(HandleRef hwnd){DestroyWindow(hwnd.Handle);HostHandle=IntPtr.Zero;}
}
// MainWindow constructor: Viewport.Child = new NativeViewport(); (88강 Border)
// 시작은 HostHandle != IntPtr.Zero 확인 후. Player를 먼저 종료한 뒤 Host를 해제한다.

BuildWindowCore(HandleRef parent) → HandleRef(child)

실패 시 Win32Exception, Airspace 제약

Windows 실기 검증 필요: Unity 6.3 공식 Windows 문서에서는 delayed 실행 및 SetParent 단계도 설명합니다. 그래픽 초기화 확인은 Unity 창의 GWLP_USERDATA 하위 비트, 스플래시 종료는 다음 비트에 따릅니다. 예제의 즉시 parentHWND 방식은 환경 확인용 출발점이며 완성된 임베딩 프레임워크가 아닙니다.
