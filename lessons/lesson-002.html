2강. Unity 프로젝트 생성

상세 수업

브라우저 저장소를 사용할 수 없습니다.

학습 목표

MachineSimulation 프로젝트를 만들고 Assets/Scenes, Scripts, Models, Prefabs 폴더를 생성한다.

핵심 개념

Universal 3D 템플릿은 URP 설정을 포함한다.

실습

01. 새 프로젝트

Hub → Projects → New project를 선택합니다.

02. 템플릿 및 저장 경로

Editor version은 6000.3.x, 템플릿은 Universal 3D로 지정합니다. 이름은 MachineSimulation, 위치는 예를 들어 C:\Dev\MachineSimulation으로 설정합니다. 실제 프로젝트 저장 폴더에 쓰기 권한이 있어야 합니다.

03. 에셋 폴더 구성

프로젝트를 열고 Project 창의 Assets에서 우클릭 → Create → Folder로 Scenes, Scripts, Models, Prefabs를 만듭니다. 이미 있는 폴더는 그대로 사용합니다.

Assets/
  Scenes/
  Scripts/
  Models/
  Prefabs/

04. 씬 저장과 실행

File → Save As로 Assets/Scenes/Main.unity에 저장합니다. Play를 눌러 오류 없이 실행되는지 확인하고 다시 Play를 눌러 종료합니다.

수업 중 제출: Unity 에디터 전체 화면과 Console 창을 캡처하세요. 오류가 있는 경우 오류 내용도 보내 주세요.
