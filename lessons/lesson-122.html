학습 목표

ConcurrentQueue에 수신 명령을 넣고 Update에서 처리한다.

핵심 개념

Unity 객체 조작은 메인 스레드에서 수행한다.

원리와 실무 적용

Unity 객체 API는 대부분 메인 스레드 전용이다. 순수 데이터를 큐에 넣고 Update에서 제한 처리한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

CommandPump.cs

파일 다운로드

using UnityEngine;
using System.Collections.Concurrent;
public class CommandPump : MonoBehaviour
{
    readonly ConcurrentQueue<CommandDto> queue=new ConcurrentQueue<CommandDto>();
    public DoorDrive door;
    public void Enqueue(CommandDto command)=>queue.Enqueue(command);
    void Update(){for(int n=0;n<32&&queue.TryDequeue(out var cmd);n++){
     if(door && cmd.command=="SetAngle" && cmd.target=="door-01" && !float.IsNaN(cmd.value)&&!float.IsInfinity(cmd.value)&&cmd.value>=0&&cmd.value<=90)door.SetAngle(cmd.value);
     else Debug.LogWarning("Rejected command");}}
}

while(n<32 && queue.TryDequeue(out var cmd)) Handle(cmd);
