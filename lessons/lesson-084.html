84강. Alarm 및 비상정지 모의 로직

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

타임아웃 발생 시 Fault로 진입하고 Reset 전 자동 재시작을 금지한다.

핵심 개념

오류 상태와 재시작 조건을 명시한다.

원리와 실무 적용

알람은 발생 원인과 상태를 기록하고 Reset 시 원인 해소를 확인해야 한다. 비상정지는 모의 로직으로만 학습한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. 81강 상태 기계에 timeout 코드 추가

02. 모의 EStop 입력으로 모든 액추에이터 Stop

03. 원인 남은 상태에서 Reset 거부

04. 원인 제거 후 Reset→Idle 확인

설정 및 계산 예제

아래는 설정값·수식·데이터 계약 또는 구현 시 필요한 코드 조각입니다. 독립 실행 프로그램 전체가 아닙니다.

FaultCode=CYL_TIMEOUT / ESTOP_SIM
