27강. Update, FixedUpdate

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

각 콜백 횟수를 계수하고 프레임 속도 변경 시 비교한다.

핵심 개념

Update는 프레임, FixedUpdate는 물리 시간 간격에 맞춰 호출된다.

원리와 실무 적용

FixedUpdate는 물리 시간 간격에 맞춰 실행되고 한 렌더 프레임에 0회 또는 여러 회 실행될 수 있다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

TickDemo.cs

파일 다운로드

using UnityEngine;

public class TickDemo : MonoBehaviour
{
    int frames,physicsTicks; float elapsed;
    void FixedUpdate()=>physicsTicks++;
    void Update(){frames++;elapsed+=Time.unscaledDeltaTime;
     if(elapsed>=1){Debug.Log($"Update={frames}, Fixed={physicsTicks}");frames=physicsTicks=0;elapsed=0;}}
}

0.02 s → 시뮬레이션 1초당 약 50회
