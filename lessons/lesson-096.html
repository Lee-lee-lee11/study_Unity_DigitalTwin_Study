96강. DataGrid

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

센서 ID, Value, UpdatedAt 열을 데이터에 바인딩한다.

핵심 개념

표 형식으로 센서 및 설비 상태를 표시한다.

원리와 실무 적용

DataGrid는 목록과 열을 연결한다. 상태 표는 ReadOnly로 두고 갱신 빈도를 제한한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. SensorRow에 Id, Value, UpdatedAt 정의

02. ObservableCollection 연결

03. AutoGenerateColumns=False

04. 명시적 열 3개

05. Mock 상태 변경

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

SensorGrid.xaml.txt

파일 다운로드

<DataGrid ItemsSource="{Binding Sensors}" AutoGenerateColumns="False" IsReadOnly="True">
 <DataGrid.Columns><DataGridTextColumn Header="ID" Binding="{Binding Id}"/><DataGridCheckBoxColumn Header="Value" Binding="{Binding Value}"/><DataGridTextColumn Header="Time" Binding="{Binding UpdatedAt}"/></DataGrid.Columns>
</DataGrid>
