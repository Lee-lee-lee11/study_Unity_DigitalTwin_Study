상세 학습 교재

학습 목표

MotorController.cs를 생성하고 Start에서 Debug.Log를 출력한다.

핵심 개념

MonoBehaviour 스크립트를 GameObject에 연결한다.

원리와 실무 적용

MonoBehaviour의 클래스명과 파일명은 일치해야 Inspector에서 컴포넌트로 부착할 수 있다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. Assets/Scripts에서 Create → Scripting → MonoBehaviour Script

02. MotorIntro 이름 지정

03. 코드 편집기에 예제 입력

04. Unity 컴파일 완료 후 Motor 객체에 드래그

05. Play와 Console 확인

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.
