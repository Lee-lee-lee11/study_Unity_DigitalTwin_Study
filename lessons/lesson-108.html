108강. MoveWindow, SetWindowPos

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

WPF SizeChanged에 맞추어 Unity 자식 창의 영역을 조정한다.

핵심 개념

네이티브 창의 픽셀 단위 위치와 크기를 갱신한다.

원리와 실무 적용

MoveWindow는 부모 기준 픽셀 좌표와 크기를 사용한다. Unity 준비 완료 후 조절한다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

NativeResize.cs

파일 다운로드

using System;
using System.Runtime.InteropServices;
public static class NativeResize {
 [StructLayout(LayoutKind.Sequential)] struct RECT{public int Left,Top,Right,Bottom;}
 [DllImport("user32.dll")] static extern bool GetClientRect(IntPtr hwnd,out RECT rect);
 [DllImport("user32.dll",SetLastError=true)] static extern bool MoveWindow(IntPtr hwnd,int x,int y,int w,int h,bool repaint);
 public static bool Resize(IntPtr host,IntPtr child){
  if(host==IntPtr.Zero||child==IntPtr.Zero||!GetClientRect(host,out var r))return false;
  int w=r.Right-r.Left,h=r.Bottom-r.Top;return w>0&&h>0&&MoveWindow(child,0,0,w,h,true);
 }
}
// Call only after verifying the Unity child HWND/PID and readiness per Unity docs.

0 크기/초기화 전 HWND 건너뛰기

Windows 실기 검증 필요: Unity 6.3 공식 Windows 문서에서는 delayed 실행 및 SetParent 단계도 설명합니다. 그래픽 초기화 확인은 Unity 창의 GWLP_USERDATA 하위 비트, 스플래시 종료는 다음 비트에 따릅니다. 예제의 즉시 parentHWND 방식은 환경 확인용 출발점이며 완성된 임베딩 프레임워크가 아닙니다.
