120강. async / await

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

CancellationToken을 적용한 비동기 읽기 루프를 작성한다.

핵심 개념

비동기 I/O로 UI 스레드의 대기를 방지한다.

원리와 실무 적용

async/await는 I/O 완료 동안 스레드를 점유하지 않는다. 취소는 토큰과 Dispose를 활용한다.
