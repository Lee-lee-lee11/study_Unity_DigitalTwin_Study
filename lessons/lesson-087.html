상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

Window에 TextBlock과 Button을 배치한다.

핵심 개념

XAML은 UI의 선언적 구조를 정의한다.

원리와 실무 적용

XAML은 객체와 속성을 선언한다. x:Name으로 코드 비하인드에서 요소에 접근한다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

MainWindow.handler.cs.txt

파일 다운로드

// Add inside the existing MainWindow partial class.
private void Start_Click(object sender, System.Windows.RoutedEventArgs e)
{
    StatusText.Text = "Running";
}

WindowContent.xaml.txt

파일 다운로드

<!-- Replace the existing Grid in MainWindow.xaml, not the Window root. -->
<StackPanel Margin="24">
  <TextBlock x:Name="StatusText" Text="Ready" FontSize="20"/>
  <Button Content="Start" Click="Start_Click" Margin="0,12,0,0"/>
</StackPanel>

TextBlock x:Name=StatusText; Button Click=Start_Click
