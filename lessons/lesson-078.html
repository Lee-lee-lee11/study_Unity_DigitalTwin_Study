78강. 분류기

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

제품 type을 A/B로 나누고 서로 다른 출구를 할당한다.

핵심 개념

제품 속성에 따라 이동 경로를 분기한다.

원리와 실무 적용

분류기는 제품 ID와 Type에 따라 출구를 배정하고, 분기 순간에 결정된 경로를 유지한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. Type A/B 데이터를 준비

02. ExitA/ExitB 빈 객체 생성

03. RouteSelector.cs에 참조 할당

04. 각 제품 도착 시 경로 선택

05. A/B 순차 5개씩 시험

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

RouteSelector.cs

파일 다운로드

using UnityEngine;

public class RouteSelector : MonoBehaviour
{
    public Transform exitA,exitB;
    public Transform Select(string type){switch(type){case "A":return exitA;case "B":return exitB;default:Debug.LogError("Unknown type");return null;}}
}

type==A ? exitA : exitB
