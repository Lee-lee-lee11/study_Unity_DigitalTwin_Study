1강. Unity Hub 및 Editor 설치

상세 수업

브라우저 저장소를 사용할 수 없습니다.

학습 목표

Windows에 Hub, Unity 6.3 LTS, Visual Studio를 설치한다.

핵심 개념

Unity Hub가 Editor 버전과 모듈을 관리한다.

실습

01. Unity Hub 설치

  1. Unity 공식 다운로드에서 Windows 설치 파일을 받습니다.
  2. 설치 파일을 실행하고 Hub를 시작합니다. Unity ID로 로그인합니다.
  3. 라이선스는 현재 사용 목적과 자격에 맞게 선택합니다.

02. Unity Editor 설치

Hub 왼쪽 Installs → Install Editor를 선택합니다.

교육 버전은 Unity 6.3 LTS(6000.3.x)입니다. 아래 공식 화면은 이전 버전이므로 실제 설치 시 6.3을 선택합니다.

03. 모듈과 Visual Studio

Windows 빌드에 필요한 지원 모듈을 선택합니다. IL2CPP를 사용하는 경우 Windows Build Support (IL2CPP)를 추가합니다. Android/iOS/WebGL 모듈은 지금 필요하지 않습니다.

Visual Studio Installer에서 Game development with Unity(유니티를 사용한 게임 개발)와 .NET desktop development(.NET 데스크톱 개발) 워크로드를 준비합니다. Unity와 WPF에서 모두 C#을 작성하기 위해서입니다.

04. 설치 검증

Hub의 Installs 탭에서 6000.3.x가 표시되는지 확인합니다. Visual Studio를 시작해 C# 개발 환경이 설치되었는지 확인합니다.
