106강. parentHWND

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

호스트 HWND를 준비한 뒤 -parentHWND 인자를 사용하여 버전별 동작을 검증한다.

핵심 개념

Unity Windows Player에 부모 창 핸들을 전달할 수 있다.

원리와 실무 적용

Unity Windows Player의 -parentHWND로 부모 HWND를 전달한다. delayed 방식은 문서의 초기화 절차를 따른다.

오류 해결

delayed는 SetParent 및 준비 비트 절차 필요; 실제 Windows 검증

Windows 실기 검증 필요: Unity 6.3 공식 Windows 문서에서는 delayed 실행 및 SetParent 단계도 설명합니다. 그래픽 초기화 확인은 Unity 창의 GWLP_USERDATA 하위 비트, 스플래시 종료는 다음 비트에 따릅니다. 예제의 즉시 parentHWND 방식은 환경 확인용 출발점이며 완성된 임베딩 프레임워크가 아닙니다.
