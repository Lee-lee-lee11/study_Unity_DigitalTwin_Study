22강. 배열과 List

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

Transform 리스트에 롤러 3개를 등록하고 foreach로 회전시킨다.

핵심 개념

부품 컬렉션을 순회해 동일 명령을 적용한다.

원리와 실무 적용

배열 길이는 고정이고 List는 추가/삭제 가능하다. Transform 참조는 실제 씬 객체를 가리킨다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

RollerGroup.cs

파일 다운로드

using UnityEngine;
using System.Collections.Generic;
public class RollerGroup : MonoBehaviour
{
    public List<Transform> rollers = new List<Transform>();
    void Update() { foreach(var r in rollers) if(r) r.Rotate(0,0,90*Time.deltaTime); }
}
