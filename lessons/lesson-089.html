89강. Data Binding

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

TextBox와 TextBlock을 같은 속성에 바인딩한다.

핵심 개념

바인딩은 View와 데이터 속성의 연결이다.

원리와 실무 적용

Binding은 DataContext를 기준으로 속성 경로를 평가한다. TwoWay는 양방향 전달이다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. MainWindow.DataContext를 SimpleVm으로 지정

02. TextBox와 TextBlock을 MotorName에 바인딩

03. UpdateSourceTrigger=PropertyChanged

04. 입력 확인

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

Binding.xaml.txt

파일 다운로드

<StackPanel><TextBox Text="{Binding MotorName, UpdateSourceTrigger=PropertyChanged}"/><TextBlock Text="{Binding MotorName}"/></StackPanel>

SimpleVm.cs

파일 다운로드

public class SimpleVm { public string MotorName { get; set; } = "Motor 01"; }
// In MainWindow constructor after InitializeComponent(): DataContext = new SimpleVm();
// 90강에서 변경 알림 추가 전에는 다른 UI의 즉시 갱신이 보장되지 않는다.

Text={Binding MotorName, UpdateSourceTrigger=PropertyChanged}
