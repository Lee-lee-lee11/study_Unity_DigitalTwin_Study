121강. Thread와 Dispatcher

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

백그라운드에서 수신한 상태를 Dispatcher.InvokeAsync로 전달한다.

핵심 개념

WPF UI는 해당 Dispatcher 스레드에서 갱신해야 한다.

원리와 실무 적용

Dispatcher는 WPF UI 소유 스레드에서 작업을 실행한다. 상태 수신은 Dispatcher를 거친다.
