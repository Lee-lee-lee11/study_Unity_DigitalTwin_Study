117강. Named Pipe Server

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

WPF에서 NamedPipeServerStream을 비동기로 열어 클라이언트를 기다린다.

핵심 개념

Windows 로컬 프로세스 사이의 스트림 서버를 구성한다.

원리와 실무 적용

NamedPipeServerStream은 로컬 연결을 수락한다. 읽기/쓰기를 직렬화하고 취소를 처리한다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

PipeServer.cs

파일 다운로드

using System.IO;
using System.IO.Pipes;
using System.Text;
using System.Threading;
using System.Threading.Tasks;
public static class PipeServer {
 public static async Task RunOnceAsync(CancellationToken token){
  using var pipe=new NamedPipeServerStream("machine-sim-demo",PipeDirection.InOut,1,PipeTransmissionMode.Byte,PipeOptions.Asynchronous|PipeOptions.CurrentUserOnly);
  await pipe.WaitForConnectionAsync(token);
  using var reader=new StreamReader(pipe,new UTF8Encoding(false),false,1024,true);
  using var writer=new StreamWriter(pipe,new UTF8Encoding(false),1024,true){AutoFlush=true};
  // Single trusted local ping/pong exercise. Production: bounded framing before decoding.
  var line=await reader.ReadLineAsync(token);
  if(line=="ping")await writer.WriteLineAsync("pong");
 }
}
// Call from an async WPF event handler; catch IOException/OperationCanceledException; cancel on closing.

pipeName=machine-sim-demo
