76강. Object Pooling

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

제품 10개를 미리 만들고 사용 후 풀에 반환한다.

핵심 개념

객체 재사용은 반복 생성/삭제 부담을 줄인다.

원리와 실무 적용

Object Pool은 재사용 시 상태 초기화가 핵심이다. 위치, 속도, 센서 상태와 구독을 복원해야 한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. ProductPool.cs로 10개 미리 생성

02. Rent로 활성화, Return으로 비활성화

03. 10개 대여 후 11번째 요청 시험

04. 하나 반환 후 다시 대여

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

ProductPool.cs

파일 다운로드

using UnityEngine;
using System.Collections.Generic;
public class ProductPool : MonoBehaviour
{
    public GameObject prefab;
    readonly Queue<GameObject> available=new Queue<GameObject>();readonly HashSet<GameObject> leased=new HashSet<GameObject>();
    void Start(){if(!prefab)return;for(int i=0;i<10;i++){var o=Instantiate(prefab,transform);o.SetActive(false);available.Enqueue(o);}}
    public GameObject Rent(Vector3 pos){if(available.Count==0)return null;var o=available.Dequeue();leased.Add(o);o.transform.position=pos;o.SetActive(true);return o;}
    public void Return(GameObject o){if(!leased.Remove(o))return;o.SetActive(false);available.Enqueue(o);}
}

Queue<GameObject> available; HashSet<GameObject> leased
