3강. Hierarchy, Inspector

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

Cube를 만들고 Frame으로 이름을 바꾼 뒤 Inspector에서 Position을 (0,1,0)으로 설정한다.

핵심 개념

Hierarchy는 객체의 관계, Inspector는 컴포넌트 속성을 보여준다.

원리와 실무 적용

Hierarchy는 씬에 있는 인스턴스 목록이고 Project는 디스크의 에셋이다. Inspector는 선택한 객체의 컴포넌트를 편집한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. Hierarchy에서 우클릭 → 3D Object → Cube

02. F2로 Frame 이름 변경

03. Inspector의 Transform Position X=0,Y=1,Z=0 입력

04. Ctrl+S로 씬 저장

설정 및 계산 예제

아래는 설정값·수식·데이터 계약 또는 구현 시 필요한 코드 조각입니다. 독립 실행 프로그램 전체가 아닙니다.
