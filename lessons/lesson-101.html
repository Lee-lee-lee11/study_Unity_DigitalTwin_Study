101강. Unity Build Profiles

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

File > Build Profiles에서 Windows 타깃을 선택하고 테스트 씬을 빌드한다.

핵심 개념

Editor 외부에서 실행하는 Windows Player를 생성한다.

원리와 실무 적용

Windows Player 빌드는 Editor 없이 실행된다. 생성된 *_Data 및 DLL을 함께 유지한다.
