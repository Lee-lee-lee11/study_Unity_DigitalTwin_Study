26강. Awake, Start

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

두 콜백에서 로그를 출력하고 초기 위치를 저장한다.

핵심 개념

Awake는 초기 참조, Start는 첫 Update 전 초기화에 활용한다.

원리와 실무 적용

Awake에서 자기 컴포넌트 참조를 준비하고 Start에서 씬 준비 이후 초기 로직을 실행한다. 객체 사이 Awake 호출 순서는 가정하지 않는다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

LifecycleDemo.cs

파일 다운로드

using UnityEngine;

public class LifecycleDemo : MonoBehaviour
{
    Vector3 initial;
    void Awake(){initial=transform.localPosition;Debug.Log(name+" Awake");}
    void Start()=>Debug.Log(name+" Start: "+initial);
}
