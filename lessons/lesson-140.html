140강. 프로젝트 저장 및 불러오기

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

버전 필드를 포함한 JSON으로 공장 배치를 저장하고 복원한다.

핵심 개념

저장 파일은 모델 ID, 경로, 위치, 설정을 보존한다.

원리와 실무 적용

저장 파일은 ID와 데이터로 복원한다. schemaVersion과 상대 경로 및 원자적 저장을 고려한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. layout.json 정의

02. ID,typeId,modelRelativePath,position,yaw,settings 저장

03. 임시 파일 작성 후 교체

04. 빈 씬 복원

05. 잘못된 경로/버전 시험

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

layout.json

파일 다운로드

{"schemaVersion":1,"unit":"m","machines":[{"id":"machine-01","typeId":"door.v1","modelRelativePath":"models/door.glb","position":{"x":1,"y":0,"z":2},"yaw":90,"settings":{"speed":45}}]}

schemaVersion=1 / machines:[...]
