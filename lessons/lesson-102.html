102강. Process 클래스

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

ProcessStartInfo로 Player를 시작하고 종료 이벤트를 처리한다.

핵심 개념

WPF가 Unity 실행 파일의 프로세스 수명을 관리한다.

원리와 실무 적용

ProcessStartInfo는 실행 경로·작업 폴더·인자를 설정한다. 프로세스 종료도 추적해야 한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. PlayerService.cs 추가

02. exe 존재 확인

03. UseShellExecute=false, WorkingDirectory 지정

04. Process.Start 및 Exited 구독

05. Dispatcher로 상태 표시

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

PlayerService.cs

파일 다운로드

using System;
using System.Diagnostics;
using System.IO;
public sealed class PlayerService {
 public Process? Player {get;private set;}
 public Process Start(string exe, IntPtr host=default){
  if(Player is {HasExited:false})throw new InvalidOperationException("Already running");
  exe=Path.GetFullPath(exe); if(!File.Exists(exe))throw new FileNotFoundException(exe);
  var psi=new ProcessStartInfo(exe){UseShellExecute=false,WorkingDirectory=Path.GetDirectoryName(exe)!};
  if(host!=IntPtr.Zero){psi.ArgumentList.Add("-parentHWND");psi.ArgumentList.Add(host.ToInt64().ToString(System.Globalization.CultureInfo.InvariantCulture));}
  Player?.Dispose(); Player=Process.Start(psi)??throw new InvalidOperationException("Start failed");Player.EnableRaisingEvents=true;return Player;
 }
 // 종료 정책 및 Exited 이벤트는 114강에서 추가. 호스트 핸들 생성 후 시작한다.
}
