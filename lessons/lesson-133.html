학습 목표

OpenFileDialog에서 GLB/JSON 경로를 선택하고 존재 여부를 검사한다.

핵심 개념

WPF에서 파일 선택 및 유효성 검사를 수행한다.

원리와 실무 적용

파일 선택은 UI 책임이며 확장자, 크기, 권한, 허용 경로를 검증한다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

FileDialog.cs

파일 다운로드

using System.IO;
using Microsoft.Win32;
public static class FileDialog {
 public static string? SelectGlb(){var dialog=new OpenFileDialog{Filter="GLB model (*.glb)|*.glb",CheckFileExists=true,Multiselect=false};
 if(dialog.ShowDialog()!=true)return null;
 var f=new FileInfo(dialog.FileName);if(f.Length>100*1024*1024)throw new IOException("File too large");return f.FullName;}
}

Filter: GLB model (*.glb) → *.glb
