10강. Mesh와 Material

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

URP/Lit 재질을 만들고 Metallic 및 Smoothness를 변경해 프레임에 적용한다.

핵심 개념

Mesh는 형상, Material은 표면 속성을 표현한다.

원리와 실무 적용

URP/Lit은 Base Map 색, Metallic, Smoothness에 따라 반사와 외관을 표현한다. 질량은 Material이 아니라 Rigidbody 속성이다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

01. Assets/Materials 폴더 생성

02. Create → Material, 이름 MetalFrame

03. Shader Universal Render Pipeline/Lit 확인

04. Metallic=0.7 Smoothness=0.6 설정 후 Frame에 드래그

05. 비금속 버전과 비교

설정 및 계산 예제
