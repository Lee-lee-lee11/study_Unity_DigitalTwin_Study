28강. Time.deltaTime

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

1 m/s로 3초간 이동하는 객체를 구현한다.

핵심 개념

시간 기반 이동은 프레임 속도에 따른 속도 차이를 줄인다.

원리와 실무 적용

거리=속도×시간. MoveTowards는 한 번에 목표를 넘지 않도록 이동량을 제한한다.

단계별 실습

별도 테스트 씬 또는 프로젝트 사본에서 진행하세요. 이전 강의와 이름이 같은 제어 스크립트가 있으면 중복 부착하지 않습니다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

MoveDemo.cs

파일 다운로드

using UnityEngine;

public class MoveDemo : MonoBehaviour
{
    Vector3 target;
    void Start()=>target=transform.position+Vector3.right*3;
    void Update()=>transform.position=Vector3.MoveTowards(transform.position,target,Time.deltaTime);
}
