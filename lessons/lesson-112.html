112강. Raycast Picking

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

ScreenPointToRay와 Raycast로 부품 ID를 읽는다.

핵심 개념

화면 좌표에서 광선을 발사하여 부품을 선택한다.

원리와 실무 적용

Picking은 화면 좌표의 Ray와 Collider 교차를 이용한다. PartId는 부모 객체에서 찾을 수 있다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

PartId.cs

파일 다운로드

using UnityEngine;

public class PartId : MonoBehaviour
{
    public string id="door-001";
}

PickDemo.cs

파일 다운로드

using UnityEngine;

public class PickDemo : MonoBehaviour
{
    public Camera cam;public LayerMask mask=~0;
    void Update(){if(cam&&Input.GetMouseButtonDown(0)){var ray=cam.ScreenPointToRay(Input.mousePosition);if(Physics.Raycast(ray,out var hit,1000,mask)){var part=hit.collider.GetComponentInParent<PartId>();if(part)Debug.Log(part.id);}}}
}
