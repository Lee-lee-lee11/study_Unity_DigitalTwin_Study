81강. State Machine

상세 학습 교재

브라우저 저장소를 사용할 수 없습니다.

학습 목표

Idle, Running, Fault 상태와 Start/Stop/Reset 전이를 정의한다.

핵심 개념

명확한 상태와 전이 조건으로 설비를 제어한다.

원리와 실무 적용

상태 기계는 허용된 전이만 수행한다. Fault는 Stop과 구분하며 Reset은 Idle로만 돌아가게 한다.

코드 / 설정 파일

파일은 개별 강의 실습용입니다. Unity .cs는 Assets/Scripts에 복사하고 클래스명과 파일명을 유지하세요. WPF .cs는 WPF 프로젝트에만 추가하고, .txt는 기존 파일의 지정 위치에 삽입하는 조각입니다. 필요한 참조는 위 실습에서 지정합니다. 이전 강의 코드를 요구하는 예제는 해당 파일을 먼저 준비합니다. 전체 프로젝트를 한 번에 컴파일한 산출물은 아닙니다.

MachineState81.cs

파일 다운로드

using UnityEngine;

public class MachineState81 : MonoBehaviour
{
    public enum State{Idle,Running,Fault} public State Current{get;private set;}
    [ContextMenu("Run")] public void Run(){if(Current==State.Idle)Current=State.Running;}
    [ContextMenu("Stop")] public void Stop(){if(Current==State.Running)Current=State.Idle;}
    [ContextMenu("Trip")] public void Trip()=>Current=State.Fault;
    public bool causeCleared;
    [ContextMenu("Reset")] public void ResetFault(){if(Current==State.Fault&&causeCleared)Current=State.Idle;}
}

Idle → Running → Fault → Idle
